# Adding a New Target

A target is a directory `targets/<name>/` containing a prepared receptor, a
docking box, and a pocket residue set. All of it — except picking the source
structure — is generated by `tools/prepare_target_fixture.py`.

The box and pocket are derived from a **ligand-free pocket detector (P2Rank)** run
on the protein, not from a bound inhibitor. This is deliberate: BioFuzz is meant
to find binders for a protein you have no drug for, so the site it searches must
be a property of the protein. A known inhibitor is never required, and never
shapes the box, the pocket, or the coverage map.

**Prerequisite:** install P2Rank with `python tools/install_p2rank.py`
(it downloads to `.tools/p2rank/`, which the builder finds automatically). P2Rank
needs a system Java >= 11 — `JAVA_HOME` or `java` on PATH — which the installer
does *not* provide. If you already have P2Rank elsewhere, putting `prank` on PATH
or setting `$P2RANK` works too. Without it the builder cannot derive a box or
pocket.

## 1. Find a source structure

Search [RCSB PDB](https://www.rcsb.org) for your protein. Either an apo
(ligand-free) or a holo (co-crystal) structure works — the pocket is detected
from the protein, so a bound ligand is not required.

Checklist when picking a PDB entry:

- **Wild-type, unless you specifically want a mutant/resistance study.**
  Many high-resolution, recently-deposited structures turn out to be mutant
  complexes — check the title and the polymer entity's mutation annotation,
  don't assume from resolution/date alone.
- **Resolution ≲ 2.5 Å.** Below ~2 Å is good; above ~3 Å, side-chain geometry
  gets unreliable, and so does the detected pocket.
- **Check whether the active site needs more than one chain.** Most targets
  are fine with a single chain. Obligate dimers whose site sits at the chain
  interface (e.g. HIV-1 protease) need both chains, or the pocket will be
  missing half its contacts.
- **Prefer a well-ordered site.** If the pocket is disordered or the loops
  lining it are missing from the model, the detector has less to work with.

## 2. Add a `TargetSpec`

In `tools/prepare_target_fixture.py`, add an entry to `TARGET_SPECS`. Three
specs beyond the two bundled targets are already there (`egfr_kinase`, `parp1`,
`braf_v600e`), kept so the five-drug threshold calibration in
[`architecture.md`](architecture.md) can be rebuilt; they are also worked
examples of this step.

```python
"my_target": TargetSpec(
    name="my_target",
    pdb_id="1ABC",                       # RCSB entry ID
    protein_chains=("A",),               # add more chains only if the site spans them
    # Optional. Literature/UniProt active-site residues -- knowledge about the
    # PROTEIN, not any inhibitor. Only used to pick which detected pocket is the
    # one you want when the catalytic site isn't the top-scoring cavity.
    active_site_residues=("A:145", "A:41"),
    # Optional. Only used to emit a validation reference ligand; never affects
    # the box or pocket. Omit for a target with no known inhibitor.
    ligand_code="XYZ",
    inhibitor_name="my_drug",
),
```

## 3. Run it

```sh
python tools/prepare_target_fixture.py my_target
```

This downloads the structure from RCSB, then automatically:

- isolates the named chain(s), strips waters/hydrogens/heteroatoms
- converts the receptor to PDBQT via Meeko's `mk_prepare_receptor.py`
- runs **P2Rank** on the apo receptor to detect binding pockets, and selects the
  top-ranked one (or the one best covering `active_site_residues`, if given)
- writes the pocket's residue set as `pocket.residue_ids` (this is exactly what
  the coverage fingerprint hashes contacts into) and derives the box from the
  pocket: center = P2Rank pocket center, size = pocket-residue extent + 8 Å
  padding, clamped to 18–28 Å
- writes a small `pocket.essential_residue_ids` set — the residues a real binder
  must engage, ranked from receptor burial + polar character and blended with
  P2Rank's per-residue ligandability. Derived from the protein alone, never from
  an inhibitor; the oracle's essential-contact tier gates on it (see
  [`architecture.md`](architecture.md)). Omitting it is harmless: the campaign
  rederives the structural half of the same set at startup, which is why
  neither bundled config carries one. Writing it at prep time
  only adds P2Rank's ligandability signal to the ranking.
- if `ligand_code`/`inhibitor_name` are set, emits an optional
  `reference_ligands/` entry (validation only — see step 4)

Output: `targets/my_target/protein.pdbqt` and `targets/my_target/config.yaml`
(box + pocket). Inspect the reported pocket rank/score, and open the box in a
viewer against the structure to confirm it lands on the site you intended — the
detector is good but not infallible.

## 4. There is no threshold to calibrate

The oracle is reference-free: every target inherits the single global oracle in
`config.yaml`. No per-target `affinity_threshold` is set from where a known drug
docks, and that is intentional — a hit gate anchored to the answer defeats the
premise of the tool. The reference-free tiers (ligand efficiency, CNN pose
confidence, vina/CNN consensus) do the discriminating.

If you did name a known inhibitor, you can *validate* the oracle by docking the
generated `reference_ligands/<name>.pdbqt` by hand and confirming it isn't
rejected outright — a sanity check on the gate, never an input to it.

**Expect some real drugs to miss the affinity tier.** Two of the five drugs
measured to set the thresholds do not clear -9.0 (see
[`architecture.md`](architecture.md)). That is the known cost of one absolute
cutoff across targets, not a sign your target is set up wrong. If your reference
drug misses it, check the *other* tiers — ligand efficiency, pose confidence,
essential contacts — before concluding anything, and rank in triage rather than
retuning the global gate.

## 5. Check the molecule bounds admit your target's chemistry

The global `molecules:` bounds (550 Da, logP 5.0) are drug-like defaults, and
they will silently reject whole classes of real drug. Molecules outside them are
dropped at preparation — before docking, with no finding and, for mutants, no log
line. The bundled hiv_protease target needs an override, because indinavir is
614 Da; when braf_v600e was bundled it needed one too, for vemurafenib's logP
of 5.54.

If your target's known drugs are large, greasy, or unusually flexible, say so:

```yaml
molecules:
  max_mw: 750
  max_rot_bonds: 16
```

Where a target ships a validation reference drug, `pytest tests/test_calibration.py`
checks that the target's own bounds can at least prepare it — a guard against
bounds that would silently exclude the target's chemical class. Let the oracle's
`min_ligand_efficiency` tier — not a blanket MW cap — keep the extra size honest;
it asks what the extra atoms are buying.

A preparation failure on a corpus entry is logged at WARN
(`[PREP] cannot prepare corpus entry, it will never be docked`). Watch for it on
a new target's first run: it is the signal that the bounds are excluding
chemistry you meant to explore.

## Known limitation

Box/pocket placement is only as good as the pocket detector and the source
structure. P2Rank is strong but not infallible: it can rank an allosteric or
crystallographic cavity above the catalytic one, or draw a pocket that clips a
flexible element. Two mitigations:

- Set `active_site_residues` on the `TargetSpec` (literature/UniProt catalytic
  residues) so the builder selects the pocket that actually covers the site you
  mean, rather than the top-scoring one.
- For a site a rigid-pocket detector genuinely can't capture — e.g. HIV-1
  protease's active site sits at the A/B dimer interface behind mobile flaps —
  hand-curate `config.yaml` and mark its first line `# hand-curated` so re-runs
  won't overwrite it. `targets/hiv_protease/` is done this way. A hand-curated
  config may omit `pocket.essential_residue_ids`; the campaign rederives the
  structure-only essential set at startup (for hiv_protease it recovers the
  catalytic aspartate dyad, A:25/B:25, unaided).

Always eyeball the generated box against the structure in a viewer before
trusting it.
